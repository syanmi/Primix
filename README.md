# Primix

**Primix** is a minimal yet essential toolkit for .NET applications.  
It provides the foundational building blocks that most applications need — such as configuration storage, logging, dependency injection, and messaging — all in a compact, dependency-light package.

Think of it as your app’s **first-aid kit**: small, self-contained, and ready to use.

## Features

- Lightweight persistent configuration storage
- Simple structured logging
- Minimal DI container
- In-process messaging/event system
- No external dependencies
- Suitable for WinForms, WPF, Console apps, and more

## Why "Primix"?

> **Primix** stands for "**Prime Mix**" — a set of carefully selected core features you’ll likely need in every project.  
It’s the **first thing you add** to a new application, before anything else.
